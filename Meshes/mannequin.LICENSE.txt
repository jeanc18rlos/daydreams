CHANGES MADE TO THIS FILE (recorded so it can be checked against a fresh download):

  This copy is NOT the set of files as downloaded. `tools/build_mannequin.py` (headless Blender)
  merges them: it imports `Mannequin.fbx` and one animation-only FBX per clip -- each downloaded
  "Without Skin" with the Mannequin selected -- and writes them out as a single GLB carrying one
  mesh, one 65-bone `mixamorig1:` skeleton and all 31 clips, each named after the file it came
  from. The character's own one-frame T-pose action is dropped so it cannot be mistaken for a
  clip. The four 4096px maps are downscaled to 1024px, the only change to any pixel: the game
  samples base colour only and looks PS1-era, and 1024 is what keeps the file at 14.6 MB.

  Nothing else is altered. No geometry, no UVs, no materials, no keyframes, and nothing is
  retargeted -- every clip was fitted by Mixamo to this same character, which is why they combine
  by a direct action copy rather than by a rigging step.

  Reproduce with:
      /Applications/Blender.app/Contents/MacOS/Blender --background --python tools/build_mannequin.py

What the file holds: one mesh (28,880 triangles, one material, four 1024x1024 PNG maps -- diffuse,
normal, specular, glossiness) skinned to a 65-joint skeleton, and 31 animation clips. The clip
names below are the file's own, and are what `src/level32.rs` and `src/ext/skinned.rs` look up.

  Picked one at a time from Mixamo's library (7):
    standing_idle, walking, running, talking, waving, opening_door_inwards, reaching_out
    -- Mixamo's "Standing Idle", "Walking (In Place)", "Running (In Place)", "Talking",
    "Waving", "Opening Door Inwards" and "Reaching Out".

  Mixamo's "Not So Scary Zombie Pack" (24):
    zombie_idle, zombie_idle_2, zombie_idle_3, zombie_idle_4, zombie_scratch_idle,
    zombie_running, zombie_stumbling, zombie_turn, zombie_transition, zombie_transition_2,
    zombie_stand_up, zombie_stand_up_2, zombie_stand_up_3, zombie_attack, zombie_punching,
    zombie_punching_2, zombie_kicking, zombie_kicking_2, zombie_headbutt,
    zombie_reaction_hit, zombie_reaction_hit_2, zombie_agonizing, and the pack's two plain
    walks, which carry no zombie prefix: walking.001 and walking_2.

The game currently plays one of the 31 (`walking`, in the Mannequin Test scene, `src/level32.rs`).
The other 30 ship unused: they are keyframes on a skeleton the file already carries, a small part
of its size next to the four maps, and the scenes that will use them are what this asset is for.
