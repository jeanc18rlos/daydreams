The intro level's door is "Classic Interior Door" (Classic_Interior_Door.glb), supplied by the
project owner and originally distributed via Sketchfab.

The GLB is loaded at runtime -- Meshes/Classic_Interior_Door.glb, by src/ext/gltf_model.rs.
Nothing is baked or converted: the model's own smooth normals, tangents, base colour, normal,
occlusion and metallic-roughness maps are what you see. The loader only fits the model to the
engine's scale.

The one change from the file as supplied is resolution: the embedded PNG maps were 4096 square
(~400 MB of decoded RGBA for a door a few hundred pixels tall on screen), and the loader was
downscaling them to 512 square on every load. They are now stored at 512 square, resized once
by tools/shrink_glb.py with the same filter the loader used; geometry and everything else in
the file are unchanged (79 MB -> 1.3 MB).
