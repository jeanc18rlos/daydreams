CHANGES MADE TO THIS FILE (nothing obliges the record -- CC0 asks nothing -- but it is kept to
the same standard as the CC-BY meshes, so a fresh download can be checked against it):

  This copy is NOT the file as downloaded. `tools/build_props.py` (headless Blender) converts
  the pack's FBX (`source/Exploration objects/Exploration_objects.fbx`) into this GLB:

  * The pack's one unnamed mesh, `Cone.001` -- the spirit box -- is renamed `Spirit_Box`.
  * Every material is set metallic 0 / roughness 1: these are PSX diffuse textures, and
    glTF's default metallic 1 would render them as dark metal.
  * Four materials get the pack's `*_Emissor.png` wired as the glTF emissive texture, so
    their screens glow unlit at night. The EMF detector ships five display states
    (`*_Emissor_00`..`_04`); the mid state `_Emissor_02` is the one wired -- a fixed mid
    reading, honest for a prop that cannot swap maps at runtime.

  Nothing else is altered: geometry, UVs, the materials otherwise, and the pack's own layout
  positions ship as authored.

  Reproduce with:
      /Applications/Blender.app/Contents/MacOS/Blender --background --python tools/build_props.py

What the file holds: the pack's 8 handheld tools -- EMF_Detector, Flashlight, Flashlight_Poquet,
Photo_Camera, Spirit_Box, Thermal_Camera, Thermometer, Voice_Recorder -- as takeable, usable
items for the scene derived from Liminal Neighborhood.
